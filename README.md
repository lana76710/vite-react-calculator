# Vite React Calculator

Jednostavna web aplikacija kalkulatora razvijena koristeći **React**, **Vite** i **TypeScript**.

## O projektu

Mini kalkulator koji podržava osnovne aritmetičke operacije:
- Sabiranje (+)
- Oduzimanje (-)
- Množenje (*)
- Deljenje (/)

UI sadrži dva input polja za unos brojeva, dugmad za operacije i prikaz rezultata.

## Live verzija

> **[https://vite-react-calculator-mauve.vercel.app](https://vite-react-calculator-mauve.vercel.app)**

## Pokretanje lokalno

### Preduslovi

- [Node.js](https://nodejs.org/) v18 ili noviji
- npm

### Instalacija i pokretanje

```bash
git clone https://github.com/lana76710/vite-react-calculator.git
cd vite-react-calculator
npm install
npm run dev
```

Aplikacija će biti dostupna na `http://localhost:5173`.

## Tehnički stack

- [Vite](https://vitejs.dev/) — build alat
- [React 19](https://react.dev/) — UI biblioteka
- [TypeScript](https://www.typescriptlang.org/) — tipizacija

## Deployment

Projekat je deploy-ovan na [Vercel](https://vercel.com) i povezan sa GitHub repozitorijumom. Svaki push na `main` branch automatski ažurira live verziju aplikacije.
